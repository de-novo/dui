Functional Core · Imperative Shell

Five crates. Strict dependency direction.

Enforced automatically in CI via npm run check:deps over cargo metadata --locked. Pure logic stays I/O-free; adapters never import one another.

Cargo Workspace Crates

Crate Responsibility Allowed Workspace Deps
dui-core Pure deterministic IR, state planning, diffing, coverage audit, storage repository traits None (0)
dui-ports Three core ports (TypeOracle, Host, Renderer), SurfaceAdapter, SurfaceRegistry, AppStore dui-core

dui-app Port-driven use cases: audit, cache, comments, diff, graph_view, inspect, compiler_oracle dui-core, dui-ports (0 adapters)
dui Single binary composition root: wires concrete adapters, CLI, MCP server, and embedded web viewer All workspace crates

Analysis and rendering by platform

dui reads types through the project’s official compiler. Rules recognize individual API calls. Each platform supplies its own evidence of what appeared on screen.

Surface What dui reads What you can see
Web A local URL or static build. A TypeScript scan can also extract typed state from recognized calls. Reachable pages captured in Chromium at the requested widths.
Desktop Declared GPUI states or Electron web renderer content with optional IPC mocks. GPUI state captures and element trees, or Electron renderer pages in Chromium.
Mobile React Navigation, Expo Router and Flutter route declarations. Native captures need an Android device or emulator, or an iOS Simulator. Source cards with file locations, optionally linked to recordings. Selected SwiftUI and Compose components also export as interactive HTML previews.
Terminal (TUI) Output from a command running in a pseudoterminal. A terminal cell grid and its PNG at the configured sizes.
