Map this demo site itself

Discovers all four pages and both native <dialog> modals with zero bundler or config file.

dui open
VITE + REACT + TANSTACK / REACT ROUTER

Full-stack SPA state & modal sweep

Reads official TypeScript declarations and generated route registries, expands WAI-ARIA sidebars, and captures every screen × modal × width. 

cd your-vite-app
dui map .
dui desktop
NEXT.JS 16 APP ROUTER

Zero-config Next.js capture & scan

Automatically detects next.config.*, discovers App Router pages and Server Component boundaries, and captures full scrollable height. 

cd your-nextjs-app
dui scan .
dui map .
AUTHENTICATED ROUTES & PR DIFF

Login once, diff every PR

Capture an authenticated browser session (form, MFA, or OAuth) into storageState.json (0600) and generate a Markdown diff table against main. 

dui auth login http://localhost:5173/login --out auth.json
dui map .
dui diff --base main --markdown

Optional dui.json Template
