# Translations (i18n)

dui's documentation is trilingual: **English**, **Simplified Chinese (zh-CN)**, and **Korean (ko)**.

## Layout

| Language | README | Docs |
|---|---|---|
| English (canonical) | [README.md](../README.md) | [docs/en/](en/) |
| Simplified Chinese | [README.zh-CN.md](../README.zh-CN.md) | [docs/zh-CN/](zh-CN/) |
| Korean | [README.ko.md](../README.ko.md) | [docs/ko/](ko/) |

Each translated document uses the same file name as its English source (for example `docs/en/design-v0.md` ↔ `docs/zh-CN/design-v0.md` ↔ `docs/ko/design-v0.md`) and starts with a language switcher line:

```
English | [简体中文](../zh-CN/<file>.md) | [한국어](../ko/<file>.md)
```

## Rules

1. **English is the source of truth.** If translations disagree with English, English wins.
2. **English first.** Every content change lands in the English file first.
3. **Same PR.** In the same PR, update the `zh-CN` and `ko` files. If you cannot, add the "outdated" banner below to the top of each file you did not update (right under the language switcher). Remove the banner when the translation catches up.
4. **Faithful translation.** Keep numbers, dates, links, code, identifiers, tables, and Mermaid diagrams identical. Translate prose, table text, and code comments only. Do not add or drop content.
5. **Markers.** Translate status markers with the glossary below. Two terms must stay distinct in every language: **unverified** (미검증 / 未验证) is only the verification status of a render cell or edge; **unconfirmed** (미확인 / 未确认) is only a fact in the docs we could not confirm from a source. **unrenderable** (렌더 불가 / 无法渲染) is a third, separate cell status and is never folded into unverified.
6. **Proper nouns.** Product, library, and person names stay as written in the source (e.g. 준혁, obora, pippip, Graphify).

### "Outdated" banner

| Language | Banner |
|---|---|
| zh-CN | `> ⚠️ 本译文可能已过时，请以[英文原文](../en/<file>.md)为准。` |
| ko | `> ⚠️ 이 번역은 최신이 아닐 수 있다. [영어 원문](../en/<file>.md)을 기준으로 본다.` |

For the README files, link to `README.md` instead of `../en/<file>.md`.

## Glossary

| English | 简体中文 | 한국어 | Meaning |
|---|---|---|---|
| state | 状态 | 상태 | One condition of a screen (values of its state slots + mocked responses) |
| state slot | 状态槽 | 상태 슬롯 | One place where state lives (store, local state, context, route, server cache, Entity) |
| screen | 界面 | 화면 | A route or root view of the app |
| snapshot | 快照 | 스냅샷 | One run's bundle of results for a commit |
| render cell | 渲染格子 | 렌더 칸 | One canvas cell = state × width (× theme / locale) |
| transition | 转换 | 전환 | An edge: `state + event → next state` |
| injection | 注入 | 주입 | Setting state from outside via dev-only build transforms |
| representative value | 代表值 | 대표값 | A value chosen mechanically from a type (0 / 1 / many, empty / long, …) |
| mock | 模拟（数据） | 목 | Generated stand-in data or responses |
| coverage | 覆盖率 | 커버리지 | Verified cells ÷ renderable cells in the denominator defined in design §8 (unrenderable cells are excluded and reported separately) |
| unverified | 未验证 | 미검증 | Status of a render cell that failed or could not be verified (never used for facts) |
| unconfirmed | 未确认 | 미확인 | A claim in the docs we could not confirm from a source (never used for cell status) |
| extracted | 已提取 | 추출됨 | Edge or fact explicit in code |
| inferred | 已推断 | 추정됨 | Edge or fact inferred by AI |
| verified | 已验证 | 검증됨 | Edge or cell confirmed by replay / verification |
| suspect | 存疑 | 의심 | Only the AI visual check failed; needs a human |
| unrenderable | 无法渲染 | 렌더 불가 | Status of a render cell that cannot be drawn in the available render environment (e.g. Apple UI without a Mac runner, system UI); shown as "unrenderable (reason)", distinct from unverified |
| unsupported | 不支持 | 미지원 | A project or module dui rejects before scanning: a stack version line first released before 2026, TypeScript below 7.0, or a non-official compiler / toolchain. Not a cell status; excluded from coverage |
